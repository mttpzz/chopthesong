# Android app (WebView on Hugging Face Spaces)

The app is a single screen: a WebView that loads the public Space. It contains no API keys
and performs no search itself. The Python backend and UI live in the Space.

## Status

Source files are written. The Gradle project (wrapper, root build files, plugin versions) is
generated by Android Studio, because the Gradle wrapper jar must come from the official
distribution and is not written by hand.

## Setup (once)

1. In Android Studio: **New Project → Empty Views Activity**.
   - Name: `chopsongs`
   - Package name: `dev.chopsongs.app`
   - Language: Kotlin
   - Minimum SDK: API 24
   - Save location: a new folder **outside** the repo, for example
     `C:\Users\Matteo\Downloads\chopsongs-android-template`. Studio will not
     create a project in a non-empty folder such as this `android/`.
   - After the first sync, copy the generated Gradle files (`gradlew`, `gradlew.bat`,
     `gradle/`, root `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`) into
     this `android/` folder.
2. Let Studio finish the first Gradle sync. Note the versions it puts in the root
   `build.gradle.kts` and `gradle/libs.versions.toml`, if present. Keep them.
3. Replace the generated files with the ones in this folder:
   - `app/src/main/AndroidManifest.xml`
   - `app/src/main/java/dev/chopsongs/app/MainActivity.kt`
   - `app/src/main/res/layout/activity_main.xml`
   - `app/src/main/res/values/strings.xml`
   - `app/build.gradle.kts`: keep the plugin versions Studio generated, change only the
     parts that differ. The file here has no versions on purpose.
4. Set the real Space URL in `app/build.gradle.kts` (`SPACE_URL`), replacing `PLACEHOLDER`.
   Use the direct address `https://<user>-<space>.hf.space`.

## Build

From Android Studio: **Build → Build APK(s)**. The debug APK goes to
`app/build/outputs/apk/debug/`.

From the terminal (after Studio has created the wrapper):

```
./gradlew assembleDebug
```

## Behaviour

- Only `https` links on the Space's host open in the WebView. Other links open in the browser.
- A page that does not finish within 60 seconds shows "The app is waking up…" with a Retry
  button. The Space pauses after 48 hours of inactivity on the free tier, so the first open can
  be slow.
- Network errors show a message with Retry.
- Permissions: only `INTERNET`.
